## Аннотация

Рассматривается задача выбора ровно `Q` предметов в один рюкзак, в которой предметы могут входить в группы с пороговыми эффектами: при достижении порога одновременно включаются скидка на учитываемый вес и бонус к полезности. Предложен жадный алгоритм, явно учитывающий активацию групповых эффектов. На 12 синтетических экземплярах при `n = 12..100` проведено сравнение с полным перебором на малых `n`. Показано, что учёт групп обязателен: без него часть экземпляров не имеет допустимого решения, а жадный алгоритм с группами уступает оптимуму в среднем на 2.79%.

## Постановка задачи

Есть один рюкзак вместимости `W_max` и `n` уникальных неделимых предметов. Нужно выбрать ровно `Q` различных предметов. Предмет `i` имеет исходный вес `w_i` и полезность `u_i`. Предмет может принадлежать не более чем одной группе; предметы вне групп также допустимы.

Каждая группа `k` задаёт порог `t_k`, скидку на вес `d_k` и бонус к полезности `b_k`. Если из группы выбрано `s_k` предметов, то

```text
y_k = 1 при s_k >= t_k, иначе y_k = 0.
```

Для предмета из группы `k` учитываемые вес и полезность равны

```text
w~_i = w_i (1 - d_k y_k / 100),
u~_i = u_i (1 + b_k y_k / 100).
```

Оба эффекта включаются одновременно и применяются ко всем выбранным предметам группы. Требуется максимизировать суммарную полезность при ограничениях

```text
sum x_i = Q,
sum w~_i x_i <= W_max,
x_i in {0, 1}.
```

Здесь `x_i = 1`, если предмет выбран. Группы не являются отдельными рюкзаками: ограничения по весу и количеству предметов общие.

## Данные и методы

Использован набор из 12 экземпляров: `n = 12, 15, 18, 20, 22, 25, 30, 40, 50, 60, 75, 100`, `Q = 10`. В каждом экземпляре 2–3 непересекающиеся группы, пороги 4–5, скидки 25–50%, бонусы 0–50%; есть предметы вне групп.

Точным методом служит полный перебор всех сочетаний ровно из `Q` предметов. Каждое сочетание оценивается единой функцией `evaluate_selection`; недопустимые по весу варианты отбрасываются. Полный перебор применён при `n <= 25`.

Жадный алгоритм с учётом групп рассматривает два правила:

1. последовательно добавляет один предмет или групповой пакет, доводящий группу до порога;
2. перебирает распределение `Q` мест по группам и жадно заполняет каждую группу по одному из правил: отношение полезности к весу, максимум полезности или минимум веса.

Каждый шаг оценивается через `evaluate_selection`, поэтому скидка и бонус учитываются по фактическому изменению веса и полезности. Из допустимых вариантов выбирается лучший по полезности. Для сравнения использован также базовый жадный алгоритм по отношению `u_i / w_i` без учёта групп.

## Результаты

На малых `n`, где возможен точный перебор, получены следующие значения полезности:

| n | Оптимум | Жадный с группами | Отклонение, % |
|---:|---:|---:|---:|
| 12 | 761.64 | 761.64 | 0.00 |
| 15 | 593.04 | 593.04 | 0.00 |
| 18 | 973.74 | 916.14 | 5.92 |
| 20 | 809.36 | 791.51 | 2.21 |
| 22 | 815.67 | 745.47 | 8.61 |
| 25 | 800.86 | 800.86 | 0.00 |

Среднее отклонение жадного алгоритма с группами от оптимума составило 2.79%, максимальное — 8.61%. Базовый жадный алгоритм по отношению `u/w` на двух из шести экземпляров не нашёл допустимого решения, а на остальных уступал оптимуму в среднем на 11.23%.

На `n = 30..100` полный перебор не применялся. Жадный алгоритм с группами нашёл допустимое решение на всех 12 экземплярах и работал менее одной секунды даже при `n = 100`. Полный перебор при `n = 25` занял около 83 с, что показывает практический предел точного метода для данного `Q`.

Групповые эффекты существенны. Без скидок и бонусов при `n = 12, 15, 20, 22` вообще не существует допустимого набора ровно из `Q` предметов. Там, где решение без групп существует, учёт групп повышает полезность на 33–72%. В решениях жадного алгоритма активируются одна или две группы; все три группы одновременно не активируются, поскольку при `Q = 10` и порогах 4–5 сумма трёх порогов превышает число мест.

## Вывод

Жадный алгоритм с явным учётом групповых порогов пригоден для экземпляров `n <= 100`: он быстро работает, всегда находил допустимое решение и на малых `n` был близок к оптимуму. Полный перебор целесообразно использовать как эталон при `n <= 25`, а не как рабочий метод. Дальнейшая работа связана с проверкой алгоритма на нескольких экземплярах каждого размера, настройкой правила выбора предметов внутри группы и сравнением с локальным поиском.
