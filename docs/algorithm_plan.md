# План алгоритмов

Алгоритмы на этом этапе ещё не реализованы. План подготовлен для последовательной разработки и проверки.

## 1. Полный перебор

Перебирать только комбинации из ровно `Q` предметов среди всех `M` предметов. Число таких комбинаций до проверки ограничения веса — `C(M, Q)`. Для каждой комбинации рассчитывать вес и полезность с групповыми коэффициентами, отбрасывать недопустимые и сохранять допустимую комбинацию с максимальной полезностью.

## 2. Жадный алгоритм

Будет разработан после проверки полного перебора. Его критерий выбора нельзя считать заданным постановкой заранее: он должен быть описан как эвристическое правило и экспериментально сравнен с точными решениями на малых экземплярах.

## 3. Проверка

На небольших экземплярах полный перебор служит точным эталоном. Для каждого алгоритма следует проверять ограничение по количеству, ограничение по скорректированному весу и итоговую полезность.

## 4. Что не входит в текущий этап

Метаэвристики, динамическое программирование и CP-SAT не реализуются до проверки базовой модели, генератора и двух запланированных алгоритмов.
