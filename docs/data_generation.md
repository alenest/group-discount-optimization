# Генератор тестовых экземпляров

Генератор реализован в `src/group_discount_optimization/generator.py`. Он создаёт **сырые входные экземпляры**, а не JSON-файл конфигурации. Формат хранения повторяет старый проект: `data.npz` с числовыми массивами и `meta.json` с вместимостью и метаданными. Каталоги организованы по размеру `data/n_<n>/instance_NNN/`.

## Содержимое экземпляра

`data.npz` содержит массивы одинаковой длины:

- `weights` — исходные целочисленные веса;
- `profits` — исходная полезность (название сохранено для соответствия старому проекту);
- `group_ids` — ID группы для каждого предмета.

`meta.json` содержит `n`, `instance_id`, `target_item_count`, `capacity`, `group_count`, `seed` и параметры каждой группы: ID, скидку на вес, бонус к полезности и количество предметов.

Каждый предмет принадлежит ровно одной группе. Скидка и бонус применяются решающим алгоритмом по формулам математической модели; генератор сохраняет именно исходные веса и полезности.

## Использование

Готовые 25 экземпляров уже сохранены в `data/`. Для обычного запуска алгоритмов генератор не нужен.

Чтобы воспроизвести набор по умолчанию:

```bash
python -m group_discount_optimization.generator --seed 42
```

По умолчанию создаются пять экземпляров каждого размера `10`, `20`, `50`, `1000`, `5000`, с тремя группами; для `n=10` выбирается ровно пять предметов, для остальных размеров — десять. Генератор записывает `data.npz`, `meta.json` и общий `manifest.csv`.

Чтобы получить отдельный экспериментальный набор:

```bash
python -m group_discount_optimization.generator --output data/experiment --sizes 10 100 1000 --instances-per-size 3 --groups 3 --seed 123
```

Одинаковые параметры и seed дают одинаковые массивы. Диапазоны чисел, распределения и правило вычисления вместимости — параметры синтетического экспериментального набора, а не дополнительные требования преподавателя.
