# План генерации тестовых данных

> Генератор пока не реализован. Этот документ фиксирует, что нужно будет определить перед написанием кода. Он не является утверждением о свойствах исходных данных преподавателя.

## Структура одного экземпляра

Будущий файл данных должен описывать:

- идентификатор экземпляра;
- максимальную вместимость единственного рюкзака `max_weight`;
- требуемое количество предметов `target_item_count` (`Q`);
- список групп;
- для каждой группы — идентификатор, процент снижения веса, процент увеличения полезности и свой список предметов;
- для каждого предмета — уникальный в рамках группы идентификатор, исходный целочисленный вес и полезность.

Каждый предмет относится ровно к одной группе. Собственной вместимости у группы нет.

## Что надо определить до реализации

1. Размеры тестовых экземпляров: число групп и число предметов в каждой группе.
2. Диапазоны исходных весов и полезностей.
3. Нужно ли делать полезность целой или допускаются другие числовые значения.
4. Как именно выбирать проценты в диапазоне 0–50%: только целые проценты или другой шаг.
5. Как задавать `max_weight`: фиксированное значение или правило относительно весов кандидатов.
6. Какие семейства тестов использовать и как обеспечивать/учитывать наличие допустимых решений.
7. Какой seed и параметры генерации сохранять для воспроизводимости.

Эти пункты являются решениями экспериментального дизайна. Они не должны незаметно добавляться к математической модели как требования преподавателя.

## Возможные семейства экспериментов

После согласования параметров генератора можно подготовить несколько серий, меняя по одному фактору:

- общий размер списка кандидатов и число групп;
- требуемое количество выбранных предметов `Q`;
- вместимость `max_weight`;
- проценты скидки на вес;
- проценты бонуса к полезности;
- способ генерации связи между весом и полезностью.

Для каждого экземпляра следует сохранять параметры генерации и seed. Старые данные проекта `knapsack-metaheuristics` не считаются готовыми тестами этой модели, поскольку структура исходной задачи отличается.
