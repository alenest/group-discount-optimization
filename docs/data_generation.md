# Фиксированный набор тестовых экземпляров

## Назначение

В каталоге `data/` лежит готовый набор из 12 экземпляров формата v4. Обычные запуски алгоритмов должны читать эти файлы напрямую. Генератор не нужно запускать перед каждым экспериментом: повторная генерация заменяет сохранённые данные.

## Состав набора

- 12 экземпляров, по одному на каждый размер `n` из набора `12, 15, 18, 20, 22, 25, 30, 40, 50, 60, 75, 100`;
- `Q=10`;
- 2–3 непересекающиеся группы;
- пороги 4 или 5;
- снижение веса 25–50%;
- бонус полезности 0–50%;
- веса и полезности — целые числа 1–100;
- в каждом экземпляре есть предметы, не принадлежащие ни одной группе.

## Формат

Каждый экземпляр хранится в каталоге `data/n_<n>/instance_001/`:

- `data.npz` — массивы `item_ids`, `weights`, `utilities` и отдельные массивы ссылок `group_NNN_item_ids`;
- `meta.json` — `n`, `Q`, вместимость, число групп, число предметов вне групп, пороги и проценты эффектов;
- `checksums.sha256` — контрольные суммы всех файлов набора, включая `data.npz`, `meta.json`, `manifest.csv` и описание набора.

Предмет физически хранится в массивах только один раз. ID из списков разных групп не пересекаются. Предмет, которого нет ни в одном списке групп, не получает групповых эффектов. Загрузчик и класс `Instance` проверяют отсутствие пересечений; случайное пересечение не будет молча принято.

## Вместимость и контрольные наборы

Для каждого экземпляра генератор рассчитывает два контрольных решения с одинаковым количеством выбранных предметов в каждой группе и вне групп:

- из лёгких предметов формируется допустимый набор ровно из `Q` предметов;
- из тяжёлых предметов формируется набор с тем же групповым распределением, который превышает вместимость.

В `meta.json` сохраняются числа выбранных предметов по группам и вне групп, необходимые для воспроизведения этой проверки.

## Чтение данных

```python
from group_discount_optimization import load_instance, evaluate_selection

instance = load_instance("data/n_20/instance_001")
print("n:", instance.n)
print("Q:", instance.target_item_count)
print("Вместимость:", instance.capacity)
print("ID вне групп:", instance.ungrouped_item_ids)

# Подставьте Q уникальных ID из instance.items.
selected_ids = {item.item_id for item in instance.items[:instance.target_item_count]}
result = evaluate_selection(instance, selected_ids)
print("Выбрано по группам:", result.group_selected_counts)
print("Активные группы:", result.active_group_ids)
print("Вес:", result.total_weight, "/", result.capacity)
print("Полезность:", result.total_utility)
print("Допустимое решение:", result.feasible)
```

## Намеренная перегенерация

Только если требуется создать другой набор, из корня проекта выполнить:

```bash
python -m group_discount_optimization.generator --seed 42
```

Генератор перезапишет содержимое `data/`. Для отдельного набора укажите другой каталог:

```bash
python -m group_discount_optimization.generator --output data/experiment --sizes 15 20 30 --instances-per-size 2 --q 10 --seed 123
```

Одинаковые параметры и seed дают одинаковые значения массивов и метаданных.
