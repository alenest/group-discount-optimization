# Генератор тестовых экземпляров

Генератор находится в `src/group_discount_optimization/generator.py`. Он создаёт готовые входные данные, а не конфигурацию для последующей генерации. Каждый экземпляр хранится в `data/n_<n>/instance_NNN/` и содержит `data.npz` и `meta.json`.

## Формат экземпляра

Размеры `10`, `20`, `50`, `1000` и `5000` означают **общее число предметов во всём экземпляре**. Эти предметы распределяются между отдельными группами; сумма размеров всех групп равна `n`.

В `data.npz` каждая группа имеет собственные массивы, например:

- `group_001_weights` и `group_001_profits` — исходные веса и полезности предметов первой группы;
- `group_002_weights` и `group_002_profits` — отдельные массивы второй группы;
- аналогично для остальных групп.

`meta.json` содержит `n`, `target_item_count` (точное число предметов `Q`, которое нужно выбрать), вместимость, seed и список групп. Для каждой группы записываются её ID, число предметов, ключи массивов, скидка на вес и бонус к полезности. Генератор сохраняет исходные целочисленные веса и полезности; проценты применяются алгоритмом по формулам математической модели.

По умолчанию для каждого размера создаются пять экземпляров. Значения `Q` и число групп варьируются между экземплярами, если заданные диапазоны позволяют это. У каждой группы свои независимые списки и собственные скидка/бонус. Диапазоны чисел и правило расчёта вместимости — параметры синтетического набора, а не дополнительные требования преподавателя.

## Использование

Из корня проекта:

```bash
python -m pip install -e ".[dev]"
python -m group_discount_optimization.generator --seed 42
```

Команда выше заново создаёт стандартный набор в `data/`, включая `manifest.csv`. После этого обычные тесты алгоритмов читают сохранённые файлы; запускать генератор перед каждым тестированием не нужно.

Параметры можно менять:

```bash
python -m group_discount_optimization.generator --output data/experiment --sizes 10 100 1000 --instances-per-size 5 --min-groups 2 --max-groups 6 --q-min 1 --q-max 100 --seed 123
```

- `--sizes` — общее количество предметов в каждом экземпляре;
- `--instances-per-size` — количество экземпляров на размер;
- `--min-groups`, `--max-groups` — диапазон числа групп, выбираемого отдельно для каждого экземпляра;
- `--q-min`, `--q-max` — диапазон точного количества выбираемых предметов `Q`. Если `--q-max` не указан, верхняя граница для каждого экземпляра равна его `n`;
- `--seed` — обеспечивает воспроизводимость набора.

Если нужно сгенерировать данные в `data/`, чтобы заменить стандартный набор, используй первую команду. Для экспериментов безопаснее указывать отдельный каталог через `--output`.
