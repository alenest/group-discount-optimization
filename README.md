# Group Discount Optimization

Генератор тестовых экземпляров задачи выбора предметов с групповыми скидками.

## Математическая модель

Есть один рюкзак вместимости \(W_{\max}\). Доступные предметы разбиты на непересекающиеся группы: каждый предмет принадлежит ровно одной группе. Из всех групп требуется выбрать ровно \(Q\) предметов.

Для предмета \(i\) группы \(k\) заданы исходный вес \(w_{ki}\), полезность \(u_{ki}\), процент снижения веса \(d_k\) и процент увеличения полезности \(b_k\). После применения коэффициентов:

\[
\widetilde w_{ki}=w_{ki}\left(1-\frac{d_k}{100}\right),\qquad
\widetilde u_{ki}=u_{ki}\left(1+\frac{b_k}{100}\right).
\]

Переменная \(x_{ki}\in\{0,1\}\) показывает, выбран ли предмет. Требуется решить:

\[
\begin{aligned}
\max\quad & U=\sum_{k=1}^{K}\sum_{i=1}^{m_k}\widetilde u_{ki}x_{ki},\\
\text{при условиях}\quad & \sum_{k=1}^{K}\sum_{i=1}^{m_k}x_{ki}=Q,\\
& \sum_{k=1}^{K}\sum_{i=1}^{m_k}\widetilde w_{ki}x_{ki}\le W_{\max},\\
& x_{ki}\in\{0,1\}.
\end{aligned}
\]

## Генерация данных

Параметры находятся в `configs/generator.json`. В текущем профиле используются размеры из предыдущего [репозитория `knapsack-metaheuristics`](https://github.com/alenest/knapsack-metaheuristics): **10, 20, 50, 1000 и 5000 предметов**. Остальные значения в конфигурации — настройки синтетических данных, а не дополнительные условия задачи.

Для генерации нужны Python 3.11 или новее. В VS Code откройте папку проекта и выполните в терминале:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m group_discount_optimization.generator --config configs/generator.json --output data/generated --seed 42
```

Команда создаёт один JSON-файл для каждого размера в `data/generated/`. Чтобы создать несколько экземпляров каждого размера, добавьте, например, `--instances-per-size 5`. Чтобы изменить начальное число генератора, укажите другой `--seed`.

В `configs/generator.json` задан профиль синтетических данных: 3 группы, `Q = 10`, целые веса и полезности от 1 до 100, целые проценты от 0 до 50. Это настройки генератора, а не дополнительные условия математической задачи. Вместимость рассчитывается по заданной доле среднего скорректированного веса `Q` предметов, но не может быть меньше веса `Q` самых лёгких предметов. Это гарантирует хотя бы одно допустимое решение. Для размера `N = 10` при `Q = 10` выбираются все предметы; чтобы изменить `Q`, отредактируйте `target_item_count` в конфигурации. `capacity_ratio_percent` управляет жёсткостью ограничения веса.

Проверка тестов:

```powershell
python -m pip install -e ".[dev]"
python -m pytest
```
