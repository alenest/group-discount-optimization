# Group Discount Optimization

Генератор тестовых данных для задачи выбора предметов с групповыми скидками и бонусами.

## Математическая модель

Имеется один рюкзак вместимости \(W_{\max}\) и \(M\) предметов, распределённых между \(K\) непересекающимися группами. Каждый предмет принадлежит ровно одной группе. В группе \(k\) находится \(m_k\) предметов, поэтому

\[
M=\sum_{k=1}^{K}m_k.
\]

Требуется выбрать ровно \(Q\) предметов. Предмет \(i\) группы \(k\) характеризуется весом \(w_{ki}\) и полезностью \(u_{ki}\). Для каждой группы заданы скидка на вес \(d_k\) и бонус к полезности \(b_k\), выраженные в процентах. После их применения учитываемые вес и полезность предмета равны

\[
\widetilde w_{ki}=w_{ki}\left(1-\frac{d_k}{100}\right),\qquad
\widetilde u_{ki}=u_{ki}\left(1+\frac{b_k}{100}\right).
\]

Введём переменную выбора

\[
x_{ki}=\begin{cases}
1, & \text{если предмет } i \text{ группы } k \text{ выбран},\\
0, & \text{иначе}.
\end{cases}
\]

Математическая модель:

\[
\begin{aligned}
\max\quad & U=\sum_{k=1}^{K}\sum_{i=1}^{m_k}\widetilde u_{ki}x_{ki},\\
\text{при условиях}\quad
& \sum_{k=1}^{K}\sum_{i=1}^{m_k}x_{ki}=Q,\\
& \sum_{k=1}^{K}\sum_{i=1}^{m_k}\widetilde w_{ki}x_{ki}\le W_{\max},\\
& x_{ki}\in\{0,1\},\quad k=1,\ldots,K,\quad i=1,\ldots,m_k.
\end{aligned}
\]

Целевая функция максимизирует суммарную полезность выбранных предметов с учётом групповых бонусов. Первое ограничение требует выбрать ровно \(Q\) предметов, второе ограничивает их суммарный вес после скидок. Бинарные переменные означают, что каждый предмет либо выбирается целиком, либо не выбирается.

## Тестовые данные

В каталоге [`data/generated/`](data/generated/) хранятся пять готовых JSON-экземпляров: на **10, 20, 50, 1000 и 5000 предметов**. Размерности взяты из проекта [knapsack-metaheuristics](https://github.com/alenest/knapsack-metaheuristics). Каждый файл содержит параметры экземпляра, группы, предметы, проценты скидок и бонусов, вместимость и число предметов, которое требуется выбрать.

Это синтетические данные, созданные генератором проекта. Настройки генерации находятся в [`configs/generator.json`](configs/generator.json). В текущем профиле используется 3 группы, \(Q=10\), исходные веса и полезности от 1 до 100, а проценты скидки и бонуса — от 0 до 50. Вместимость рассчитывается по заданному в конфигурации правилу.

## Запуск генератора

Требуется Python 3.11 или новее. Команды выполняются из корневой папки репозитория.

Создать и активировать виртуальное окружение в **Git Bash**:

```bash
python -m venv venv
source venv/Scripts/activate
```

Установить проект:

```bash
python -m pip install -e .
```

Сгенерировать экземпляры в `data/generated/`:

```bash
python -m group_discount_optimization.generator --config configs/generator.json --output data/generated --seed 42
```

По умолчанию создаётся по одному экземпляру каждого размера. Чтобы создать по пять экземпляров каждого размера, добавьте `--instances-per-size 5` к команде запуска. Параметр `--seed` задаёт начальное значение генератора случайных чисел, чтобы результаты можно было воспроизвести.
