Почему возникали ошибки из лога
================================

Архив v4 был распакован поверх существующего checkout старой версии. При обычной
распаковке архив заменяет совпадающие файлы, но не удаляет файлы, которых в архиве
нет. Поэтому в рабочем каталоге одновременно остались:

- старый tests/test_instances.py с тестами для прежнего формата;
- старые каталоги data/n_*/instance_* с format_version 2;
- новый загрузчик v4, который закономерно отказывается читать format_version 2;
- новый тестовый набор v4, который закономерно обнаруживает лишние каталоги и файлы.

Это не ошибка установки pip и не основание ослаблять тесты или делать загрузчик
совместимым с прежней моделью: старые тесты и данные проверяют другую постановку.

Как избежать проблемы
=====================

1. Распаковать архив group-discount-optimization-v4-clean.zip в новый пустой каталог.
2. Открыть терминал именно в распакованном каталоге.
3. Создать отдельное виртуальное окружение и установить этот проект:

   python -m venv .venv
   source .venv/Scripts/activate      # Git Bash на Windows
   python -m pip install -e ".[dev]"
   python -m pytest

Ожидаемый результат: 17 passed.

Не копируйте старые data/ и tests/ в новый каталог. Не запускайте генератор перед
экспериментами: фиксированные данные уже включены в архив.

Версия Python-пакета в этой сборке — 0.4.0; версия формата файлов экземпляров — 4.
