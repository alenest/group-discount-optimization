# Математическая модель задачи с пороговыми групповыми эффектами

## 1. Постановка

Есть один рюкзак вместимости `W_max` и `n` уникальных неделимых предметов. Требуется выбрать ровно `Q` различных предметов. У каждого предмета есть постоянный ID, исходный вес и полезность.

Предмет может принадлежать **не более чем одной группе**. Он также может не принадлежать ни одной группе. Группа задаёт два эффекта: снижение учитываемого веса и увеличение полезности. Оба эффекта включаются одним порогом.

## 2. Обозначения

- `I` — множество всех предметов, `|I| = n`;
- `G_k` — множество ID предметов группы `k`;
- `K` — число групп;
- `w_i` — исходный вес предмета `i`;
- `u_i` — исходная полезность предмета `i`;
- `t_k` — порог активации эффектов группы `k`;
- `d_k` — снижение веса группы `k` в процентах;
- `b_k` — бонус полезности группы `k` в процентах;
- `W_max` — вместимость единственного рюкзака;
- `Q` — точное число выбираемых предметов;
- `x_i ∈ {0,1}` — признак выбора предмета `i`.

Множества групп попарно не пересекаются:

\[
G_k\cap G_l=\varnothing,\quad k\ne l.
\]

Предметы, не входящие ни в одно `G_k`, остаются доступными для выбора, но не получают групповых эффектов.

## 3. Порог активации

Количество выбранных предметов группы `k`:

\[
s_k=\sum_{i\in G_k}x_i.
\]

Оба эффекта группы одновременно активируются при достижении порога:

\[
y_k=\begin{cases}
1,&s_k\ge t_k,\\
0,&s_k<t_k.
\end{cases}
\]

Таким образом, `item_count = |G_k|` — это количество предметов, состоящих в группе, а `t_k` — отдельный порог. Эти значения не следует смешивать.

## 4. Учитываемые вес и полезность

Если предмет `i` принадлежит группе `k`, его учитываемые вес и полезность равны:

\[
\widetilde w_i=w_i\left(1-\frac{d_k y_k}{100}\right),
\qquad
\widetilde u_i=u_i\left(1+\frac{b_k y_k}{100}\right).
\]

**Оба эффекта применяются ко всем выбранным предметам группы**, если порог достигнут. Они не применяются только к предметам сверх порога и не действуют до достижения порога. Например, при `t_k=4` скидка и бонус начинают действовать сразу на все четыре выбранных предмета группы.

Если предмет не входит ни в одну группу, то `\widetilde w_i=w_i` и `\widetilde u_i=u_i`.

## 5. Оптимизационная модель

\[
\max\quad U=\sum_{i\in I}\widetilde u_i x_i
\]

при условиях

\[
\sum_{i\in I}x_i=Q,
\]

\[
\sum_{i\in I}\widetilde w_i x_i\le W_{\max},
\]

\[
x_i\in\{0,1\},\quad i\in I.
\]

Первое ограничение требует выбрать ровно `Q` различных предметов. Второе ограничивает общий учитываемый вес в одном рюкзаке. Отдельных ограничений вместимости для групп нет.

## 6. Проверка допустимости

Решение допустимо, если одновременно выполняются два условия:

1. выбрано ровно `Q` различных предметов;
2. сумма их учитываемых весов не превышает `W_max`.

Функция `evaluate_selection` в `src/group_discount_optimization/evaluation.py` является единой реализацией этих правил. Все будущие алгоритмы должны оценивать решения через неё, а не дублировать пороговую логику.

## 7. Линеаризация порога для точных решателей

Для ILP/CP-SAT можно ввести бинарную переменную `y_k`, равную единице при активации эффектов группы. При `s_k=\sum_{i\in G_k}x_i` условие порога задаётся так:

\[
s_k\ge t_k y_k,
\]

\[
s_k\le (t_k-1)+(|G_k|-t_k+1)y_k.
\]

Для каждого членства `i\in G_k` вводится `z_{ik}=x_i y_k` и ограничения:

\[
z_{ik}\le x_i,\quad z_{ik}\le y_k,\quad z_{ik}\ge x_i+y_k-1.
\]

Тогда учитываемый вес можно записать как

\[
\sum_i w_i x_i-\sum_k\sum_{i\in G_k}\frac{w_i d_k}{100}z_{ik}\le W_{\max},
\]

а полезность — как

\[
\max\sum_i u_i x_i+\sum_k\sum_{i\in G_k}\frac{u_i b_k}{100}z_{ik}.
\]

Так как группы не пересекаются, у предмета не возникает неоднозначности при применении нескольких групповых коэффициентов.

## 8. Параметры первого фиксированного набора

Это параметры начального синтетического набора для проверки модели, а не дополнительные ограничения общей задачи:

| Параметр | Значение |
|---|---:|
| Число экземпляров | 12 |
| Число уникальных предметов `n` | 12, 15, 18, 20, 22, 25, 30, 40, 50, 60, 75, 100 |
| Требуемое число предметов `Q` | 10 |
| Число групп `K` | 2 или 3 |
| Порог группы `t_k` | 4 или 5 |
| Снижение веса `d_k` | 25–50% |
| Бонус полезности `b_k` | 0–50% |
| Исходный вес и полезность | целые числа 1–100 |
| Предметы вне групп | есть в каждом экземпляре |

Преподаватель просил на первом этапе ограничиться 10–15 примерами, `n` не более 100, 2–3 группами и скидками 25–50%. В набор включено 12 экземпляров. Диапазон бонуса 0–50% сохранён как параметр модели; его диапазон является настройкой синтетических данных, а не отдельным указанием из приведённого комментария преподавателя.

Для каждого экземпляра генератор сохраняет контрольное распределение `Q` предметов, при котором активируется хотя бы одна группа и соблюдается вместимость, а также более тяжёлое распределение с тем же количеством выбранных предметов в каждой группе и вне групп, которое не помещается в рюкзак. Это позволяет проверять оценщик на заведомо допустимом и заведомо недопустимом случаях.
