# Готовые экземпляры v3

Здесь находятся 12 готовых экземпляров для задачи с пороговыми групповыми скидками. Они имеют `n` от 12 до 100, `Q=10`, 2–3 группы, пороги 4–5 и скидки 25–50%. Все предметы имеют уникальные ID. В этом первом наборе группы не пересекаются, чтобы проверить пороговую скидку без неоднозначности объединения эффектов нескольких активных групп.

Загружать экземпляр можно через `load_instance`; пересоздавать данные перед каждым запуском алгоритмов не нужно. Для полной перегенерации из корня проекта выполни:

```bash
python -m group_discount_optimization.generator --seed 42
```
