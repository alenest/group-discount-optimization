# Готовые сырые экземпляры

Каталоги организованы по общему числу предметов `n` в экземпляре. Предметы разделены на группы, и сумма размеров всех групп равна `n`.

Каждый экземпляр содержит:

- `data.npz` — отдельные пары массивов `group_NNN_weights` и `group_NNN_profits` для каждой группы;
- `meta.json` — вместимость, точное число выбираемых предметов `Q`, seed и параметры каждой группы;
- `manifest.csv` в корне `data/` — индекс набора.

В стандартном наборе пять экземпляров для каждого размера: `10`, `20`, `50`, `1000` и `5000`. Число выбираемых предметов и количество групп различаются между экземплярами. Скидки на вес и бонусы к полезности заданы отдельно для каждой группы.

Генератор не нужно запускать перед каждым тестированием: готовые данные уже сохранены. Чтобы полностью пересоздать стандартный набор, из корня проекта выполни:

```bash
python -m group_discount_optimization.generator --seed 42
```

Пример загрузки:

```python
from group_discount_optimization.instance import load_instance

instance = load_instance("data/n_50/instance_001")
for group in instance.groups:
    print(group.group_id, group.weights, group.profits)
```
