# Готовый набор v4

В каталоге находятся 12 фиксированных экземпляров `n=12..100`, `Q=10`. В каждом экземпляре 2–3 непересекающиеся группы и отдельные предметы, не входящие ни в одну группу. Порог каждой группы равен 4 или 5. При достижении порога одновременно включаются скидка на вес (25–50%) и бонус полезности (0–50%); оба эффекта относятся ко всем выбранным предметам группы.

Загружайте готовые экземпляры через `load_instance`. Файл `checksums.sha256` фиксирует контрольные суммы всех экземпляров и манифеста. Автоматические тесты сверяют эти суммы, поэтому случайная правка данных будет обнаружена. Не запускайте генератор перед обычным тестированием алгоритмов: данные уже подготовлены и зафиксированы. Намеренная перегенерация стандартного набора заменяет содержимое этой папки и обновляет контрольные суммы.
